# Online Shopping Database
The project requires a thorough understanding of database normalization, data  integrity, and query optimization.  In this work, I built and implemented 
a relational database for an online shopping website. The goal was to import data from  CSV files into organized tables, create associations between them, and run various SQL queries to extract useful insights. 

## 🛠️ Features
- Database design entails creating a well-structured database with suitable primary and foreign key restrictions.  
- Data Import and Validation-- Importing CSV data, verifying accuracy, and validating relationships.  
- Query Development-- Creating SQL queries to address specific business issues, and enhance data retrieval. 
- Performance considerations include ensuring queries are efficient and optimizing them through correct joins.

# 🎯 Project Goals
- Design a normalized relational database to support an online shopping platform.
- Import customer, product, order, and payment data from CSV files into SQL Server.
- Establish proper primary and foreign key constraints for data integrity.
- Write T-SQL queries to extract insights like customer behavior, payment summaries, and product demand.
- Implement stored procedures to apply business logic, such as conditional discounts.
- Provide optimized and well-documented SQL code for maintainability and scalability.

# 🛠️ Technologies Used
- SQL Server 2019 – Database platform for building and testing.
- T-SQL (Transact-SQL) – For writing queries, joins, constraints, and procedures.
- SQL Server Management Studio (SSMS) – Interface for interacting with the database.
- CSV Files – Used for importing structured raw data into respective tables.
